A browser tactical FPS scene built with Three.js. Open `game/index.html` with the included server:

```bash
node serve.ts
```

Then open `http://localhost:8080/game/`.

Bounty: https://make.fun/bounty/threejs-fps-02
Repository: stevan-99/tactical-fps-threejs

Controls: click to deploy, WASD to move, mouse to aim, left mouse to fire, R to reload.
